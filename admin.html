¿Cómo creo la llave de acceso? (solo una vez)
  1. Inicia sesión en GitHub con la cuenta ComfamiliarNarino y abre github.com/settings/personal-access-tokens/new.
  2. Token name: «Panel valla RA». Expiration: 1 año.
  3. Resource owner: ComfamiliarNarino. Repository access: Only select repositories → RA.
  4. Permissions → Repository permissions: Contents = Read and write y Actions = Read-only.
  5. Haz clic en Generate token, copia la llave y pégala aquí. No la compartas: quien la tenga puede cambiar la valla.

2. Imágenes de la valla

Formato ideal: 1080 × 1620 px, vertical (2:3). También sirven 1024 × 1536. Se muestran en este orden, en bucle. Usa ↑ ↓ para ordenar, cambia los segundos y elige la transición con la que entra cada imagen. Máximo 10 imágenes.

Tamaño y altura de la valla

El alto de la valla se calcula solo para mantener la proporción 2:3.
